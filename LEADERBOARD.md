# 404 Fellowship — 2026 Season

Static. Sovereign. Slightly unhinged.

This page illustrates how contributions are evaluated.

We do **not** use points.
We use four dimensions.

Small changes can score highly.
Refactors are respected.
Noise is not rewarded.

---

## 🧭 The Four Dimensions

Each merged PR is evaluated across:

| Dimension      | Scale                                   | What It Means                                         |
| -------------- | --------------------------------------- | ----------------------------------------------------- |
| **#awesome**   | meh / wow / by Turing’s beard           | Did it create delight or impact?                      |
| **#craft**     | loose / solid / surgical                | How clean and careful was the execution?              |
| **#coherence** | random / aligned / disturbingly aligned | Does it fit the tone and purpose of the 404 page?     |
| **#entropy**   | contained / playful / destabilizing     | Did it increase chaos responsibly — or unnecessarily? |

This is not a competition.
This is a classification ritual.

## 🌟 Hall of Coherence

The four canonical awards:

* **By Turing's Beard** — the moment the room involuntarily laughs.
* **Most Surgical** — smallest diff, biggest improvement.
* **Most Disturbingly Aligned** — absurdity that increases reliability.
* **Most Destabilizing (Used Responsibly)** — chaos that teaches.

Bonus category: **Refactor Positive** (you removed entropy).
Anti-category: **Glitter Bomb** (you added entropy without meaning).

Illustrative recognitions (from the sample leaderboard above):

* **By Turing's Beard** → @noah-phase
* **Most Surgical** → @alex-entropy
* **Refactor Positive** (bonus) → @lena-refactor

The Disturbingly Aligned and Destabilizing awards remain open. Real fellows will populate them as the season progresses.

You can win with one excellent PR.

# 📜 What Gets You Fellowship Energy

We look for:

* Care
* Restraint
* Humor with purpose
* Refactoring discipline
* Clear commit messages
* Understanding the tone

We do not reward:

* Tiny PR spam
* Obfuscated cleverness
* Dependency creep
* Chaos without meaning

If we have to ask whether it’s safe, it’s not.
